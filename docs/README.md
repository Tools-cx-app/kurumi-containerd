# KurumiContainerd documentation / 文档

Choose a language / 选择语言：

- [简体中文](zh/README.md)
- [English](en/README.md)

Each language directory uses the same filenames. Use the language links at the
top of a guide to switch languages without changing topics.
两种语言使用相同的文件名，页面顶部的语言链接可切换当前主题。

```text
docs/
├── README.md
├── zh/
└── en/
```

New users can start with [快速开始](zh/getting-started.md) or
[Getting started](en/getting-started.md).

When updating documentation, keep both language editions aligned, use relative
links, and place new guides under both language directories.
更新文档时请同步两种语言，使用相对链接，并将新增主题放入对应的语言目录。
